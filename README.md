# Project Name:   Quiz-Application

## Overview
**Project Purpose:**

This project builds a quiz application using the Vite frontend framework and React. The application presents users with a quiz consisting of questions loaded from a JSON data file. Users must answer questions within a time limit and can view their answers and performance after completing the quiz.

**Requirements:**

The project requires Node.js and npm installed on the system. To run the application, you must install the dependencies listed in the 'package.json' file using npm. The project uses Vite for development and Tailwind CSS for styling. The 'postcss.config.js' and 'tailwind.config.js' files contain the necessary configurations for these tools. The application is structured using React components stored in the 'src' directory, with the main component being 'main.jsx'. Data is managed using Redux and stored in the 'data.json' file.

## Getting Started
## Installation Instructions for **Quiz Application**

### 1. Cloning the Repository

**Terminal Commands:**

```sh
# Linux or macOS
git clone https://github.com/Shivam2534/Quiz-Application.git

# Windows (using Git Bash)
git clone https://github.com/Shivam2534/Quiz-Application.git
```

### 2. Dependency Installation

**Terminal Commands:**

```sh
# Linux or macOS
npm install

# Windows (using Git Bash)
npm install
```

### 3. Configuration Setup

**No additional configuration needed.**

### 4. Running the Project Locally

**Terminal Commands:**

```sh
# Linux or macOS
npm start

# Windows (using Git Bash)
npm start
```

### Additional Notes:

- The project uses Vite as a development server.
- The application is served at `http://localhost:3000` by default.
- You may need to update the `postcss.config.js` file with your preferred settings if you encounter any styling issues.
- The following tools are being used:
  - Node.js v16+
  - npm v7+
  - Vite
  - PostCSS
